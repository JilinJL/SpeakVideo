# 独立版验收记录 · 2026-10-19

此文仅记录 main 独立版本轮证据。divide 的远端架构与旧验收不能替代独立版实测。当前为发布候选，尚未完成所有目标平台的真实 GPU 验收。

## 本轮通过

| 项目 | 实际结果 |
|---|---|
| macOS Apple Silicon | arm64、32 GB 统一内存，Python 3.11、Torch 2.7.1、qwen-tts 0.1.1，MPS float32 |
| 从空推理环境安装 | 管理器创建独立环境、安装固定依赖、执行设备探测成功 |
| 默认模型下载 | 从官方 Hugging Face 下载完整 0.6B Base，结构、文件长度与下载后 SHA256 校验通过 |
| 0.6B 克隆与配音 | 使用本机系统生成的英文参考句克隆测试角色，再合成中文，24 kHz PCM WAV；单句 3.04 秒 |
| 真实作品导出 | 两行真实模型配音，完整 WAV/MP3/SRT/时间线及 1080×1920、30 fps H.264/AAC MP4；约 5.6 秒 |
| 1.7B Base | 复用本机已有完整模型；在该档位重新克隆并合成中文，24 kHz、3.68 秒 |
| VoiceDesign | 复用已有完整模型，真实描述试音 24 kHz、3.12 秒，之后切回 Base 再合成成功 |
| 模型兼容性 | 0.6B 音色用于 1.7B 时明确拒绝，提示切回档位或重新克隆 |
| 受限 PT 加载 | 新音色正常加载；含任意 pickle 对象的样本被拒绝，未执行对象 |
| 工作台依赖隔离 | 导入 Web 应用不导入 Torch / qwen_tts；无模型和 LLM 仍可启动、查看与编辑 |
| 自动回归 | 200 项 Python 测试通过；包含模型损坏、端口占用、进程归属、任务互斥、配置迁移、缓存和创作回归 |
| LLM 接口 | 模拟兼容服务验证免 Key／有 Key 的模型发现、完整结构化剧本校验；保留流式、失败切换及 Key 脱敏回归 |

用户运行时的音色、原声、模型、工程、安装日志与成片保存在被忽略的目录。发布包额外包含作者明确选择的八个角色示例 PT；README 包含一个已有成片的压缩展示副本，按路径与 SHA256 清单放行，许可边界见相邻 NOTICE。1.7B 和 VoiceDesign 复用了已有权重，不将其记为本轮下载验收。离线模式和本地模型加载已使用；未断开整台机器网络来做物理断网测试。

## 干净安装与浏览器

独立目录干净克隆后执行 `bash scripts/install.sh --no-start` 成功；无模型、无 LLM、无用户音色、环境不含 Torch 时仍通过 Web 首页、工程与运行状态接口检查。浏览器已验收首次初始化、Ollama 默认地址和免 Key 输入、服务就绪、后台真实试音完成与播放器、页面重载及成片加载。成片播放器 readyState=4、1080×1920、error=null；窄屏检查无横向溢出，浏览器未记录控制台错误。

源码、wheel、sdist 的配置规则检查通过；公开候选的全部可达历史另经规则扫描与 Gitleaks 8.30.1 扫描。候选仅保留 main/divide 引用；应用检查点、个人工程、音色、旧截图与私人部署日志不进入公开历史。扫描结果不替代后续人工审阅。

## 验收边界

- Windows NVIDIA、Linux NVIDIA：已实现平台依赖、入口和设备策略，尚未在真实机器完成本轮独立安装／克隆／MP4 导出。
- 三平台 GitHub Actions 的最新状态见 README 徽章；自动测试不能替代真实 GPU 安装、克隆与视频导出验收。
- ModelScope 下载路径、真实网络断点续传、磁盘耗尽、GPU 内存耗尽等仍需对应环境实测；自动测试只覆盖可隔离的错误路径。
- 本轮未连接真实云端／本地 LLM 推理服务；接口夹具不能代表特定供应商或模型兼容性。
- 麦克风硬件录制、整机重启、物理断网、长剧本压力与完整三平台模型组合验收仍待进行。
- 当前依赖带一条 Starlette TestClient 的 httpx 弃用提示，不影响本轮测试通过。

## 图文教程与内置示例

八个 PT 均通过受限加载及模型档位校验，四个 1.7B 原始示例生成了真实参考音频，四个重新克隆的 0.6B 示例分别通过真实短句合成。首次自动导入、切换模型补充示例、显式恢复及不覆盖用户文件已通过接口回归，页面实际验证保留已有文件。README 采用实际工作台截图，并用默认 0.6B 的懒羊羊与喜羊羊制作四句短片，实际完成配音合并、封面及 19.8 秒、720×1280 / 24 fps H.264/AAC MP4 导出，页面确认四阶段完成；重载后播放器 readyState=4、error=null，字幕和角色贴图可见。
