# SpeakVideo Logo：对话中的思考

核心理念：**两个声音，一场深入的思考。**

蓝色和橙色的简笔线条分别代表两个说话人。两组对话形态共同构成大脑轮廓，把自然交流、大胆提问和深入解释统一在一个符号里。

- **整体是大脑**：表达内容经过思考、有解释的深度，也呼应项目对高质量对话的追求。
- **局部是对话**：两侧相向的对话线条表达提问、回应与追问，体现思考在交流中展开。
- **蓝橙是两个声音**：沿用工作台的说话人配色，帮助建立产品与标志之间的联系。颜色区分说话人，不固定谁负责提问或回答。
- **留白与圆润线条**：用较少的线条保留识别特征，呈现开放、亲近的交流感。

本方案去掉播放符号，把品牌表达集中在“通过对话产生有深度的内容”。
