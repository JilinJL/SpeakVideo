# SpeakVideo Logo 设计理念

核心概念：**让对话成为作品。**

SpeakVideo 从两个人自然的交流出发，把敢问、追问和详细解释整理为台词，再转成可以听、可以看的内容。标志以两个对话气泡和中间的播放留白，表达这条路径。

## 图形语言

- **双气泡**：蓝色与橙色各代表一个说话人。两块形状相互呼应、分量接近，表达交流与接话，而非单向宣讲。
- **播放留白**：中央朝右的三角形由两块气泡之间的空隙形成，表达对话被转化为可播放的音频和视频。播放符号与气泡共用轮廓，减少独立元素。
- **蓝橙配色**：沿用工作台两位说话人的蓝、橙色系，让不同声音在同一个标志中保持各自的辨识度。
- **圆角轮廓**：让形象贴近友好的自然聊天，同时保留清楚的几何结构。

## 这次简化

移除了原版内部的多条波形切口和独立播放图形，保留两块主形状及中央留白。减少细节有助于侧栏、标签页等小尺寸场景的辨认；最终使用时仍应根据实际尺寸检查边缘和留白。

## 交付与使用

- 图形文件：`speakvideo/static/brand/speakvideo-logo-v2.png`。
- 尺寸：1254 × 1254，PNG，含真实透明通道。
- 文件由内置 ImageGen 基于原版 Logo 简化生成。
- 可与单独排版的 `SpeakVideo` 字标组合使用；当前图形本身不含文字。
- 保持原始比例，适合浅色工作台背景；深色背景下应另行检查对比度。
- 本次交付为 PNG，未生成 SVG 矢量源文件。

生成提示词保存在同目录的 `brand-logo-prompt.md`。
