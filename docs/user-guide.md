# 使用指南

## 启动

安装和日常启动入口见 README。页面默认位于 `http://127.0.0.1:8765`。第一次打开空工作区会显示本机模型引导；以后从侧栏「本机模型」进入。未安装模型时可以先编辑剧本。

## 一个完整作品

第一次使用建议跟随 [README 图文教程](../README.md#跟着做完成第一个作品)，先完成四句对话。四个内置角色会按当前模型档位首次导入；默认 0.6B 选择「示例06B」，1.7B 选择「示例17B」。缺失时在音色库点击「导入内置音色」恢复，不覆盖已有文件。原始角色及声音不因此获得源码的 Apache-2.0 授权，见 [素材说明](../speakvideo/assets/example-voices/NOTICE.md)。

1. **新建工程**：填写名称、话题和关键词。
2. **剧本**：配置 LLM 后生成草稿、修改并生成台词；也可直接手写或导入工程。全局提示词跨工程共享，JSON 契约只读。
3. **声音**：音色库中上传或录制有权使用的原声，选择有效片段并填写其准确台词，再创建音色。新音色可试听、改名、替换与删除。
4. **绑定**：给 P1（橙色）和 P2（蓝色）选择角色，逐项映射台词情绪并确认绑定。缺失映射会在预检中报错。
5. **生成**：连续同音色台词按组合成，试听后可重做选定组。内置模型串行执行推理；前端并发窗口用于请求编排，不代表同一设备并行加载多个模型。
6. **混音**：合并音频，可添加 BGM、人声闪避；导出 WAV、MP3、SRT。
7. **视频**：上传图片／长视频，编辑多个使用片段、速度和顺序；设置横竖屏、白色描边字幕、透明角色贴图与发言泛光。
8. **导出**：预览并合成 MP4，可另外生成标题封面。修改字幕、画面或封面时，复用仍然有效的音频。

台词有稳定 ID；改变排序或停顿可以复用有效配音。改变文字、音色、模型档位或运行版本会使对应声音过期。已有成片在新版本成功前保留。

## 描述音色

先在本机模型页下载 VoiceDesign。音色工厂填写描述和试听台词，生成并试听。满意后用这段音频和相同台词克隆成 Base 音色，再绑定工程。Base 与 VoiceDesign 切换需要重新加载模型。

## LLM

添加云端／本地模板，填模型名，保存并测试。免认证的本地接口可以不填 Key。模型发现只列出服务实际返回的模型；模型下载、加载由 Ollama、LM Studio 或其他运行时负责。

可分别测试普通文本和 JSON。不支持结构化结果的模型可能无法生成合格台词；使用手工编辑，或切换合适模型。错误与完整输出可在终端查看，密钥不会回显。

## 数据与恢复

工程、音色、原声、试听和成片保存在本机，不随 Git 上传。请同时备份 `.cache/` 中的私有 LLM 配置及项目数据。暂停或服务重启后重新提交任务；完成并校验过的声音可继续复用。

新格式 PT 可安全加载；旧文件转换、离线目录、安装修复与卸载见[部署与恢复](deployment.md)。
