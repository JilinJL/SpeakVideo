# divide 使用指南

按 deployment.md 启动工作台与远端服务，在侧栏连接状态确认网关、Worker 和 Qwen 就绪。

1. 新建工程，手工编辑／导入剧本，或配置兼容 OpenAI 的语言模型生成草稿与结构化台词。
2. 使用自己有权使用的参考原声创建音色；在音色库试听后，为 P1/P2 配置情绪映射并确认绑定。
3. 生成配音，按组重试失败内容；修改台词会使相关缓存失效。合并 WAV/MP3、字幕与时间线，配置 BGM。
4. 添加图片／视频素材，选取多个片段与顺序；设置角色贴图及发言泛光、中文字幕、封面后导出 MP4。

P1 为橙色、P2 为蓝色，字幕白字配角色颜色描边。画面调整只需重新合成视频，仍有效的配音可以复用。确认完整音频后，再检查成片并打包交付。

Gateway 模式从 Windows 资产库拉取音色；direct 模式使用本机 Qwen 音色目录。替换或删除绑定中的音色会影响工程，先检查使用情况并保留自己的备份。

离线演示 uv run speakvideo demo 仅用测试音与示例角色，需要准备占位／测试音色文件；不附带任何真人音色。新手希望页面内安装模型时使用 main。
