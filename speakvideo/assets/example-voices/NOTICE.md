# 内置角色音色说明

本目录包含作者从本人本机音色库中选出的四个演示角色：熊大、熊二、喜羊羊、懒羊羊。角色名称仅用于标识演示音色，没有与角色权利方的合作或背书关系。

- `base/`：1.7B Base 音色，由本机旧 PT 通过仅允许官方 `VoiceClonePromptItem` 的受限加载方式读入，再保存为 `speakvideo.voice.v1` 张量与普通数据格式；没有执行任意 pickle 加载。
- `base-small/`：先使用上述 1.7B 音色合成一段参考语音，再用 0.6B Base 重新克隆。它是适配不同模型档位的演示版本，声音表现可能不同于原始角色。
- `manifest.json`：记录每个文件的模型档位、角色、情绪、字节数与 SHA256。每个模型四个 PT，模型权重本身不随源码分发。

这些角色及原始声音的权利属于相应权利人。作者提供了本机文件作为功能演示，未取得或声称取得第三方角色、原始录音的开放再分发许可。这些素材不适用 SpeakVideo 源码的 Apache-2.0 许可，也不构成商业使用授权。需要开放许可或商业使用时，请替换为自行录制或取得相应授权的声音。

工作台仅复制当前模型的示例到本机 `voices/`。`示例06B` 对应 0.6B，`示例17B` 对应 1.7B；首次导入、切换模型、恢复缺失音色均不会覆盖已有同名文件。
